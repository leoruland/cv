# Coding Agent Instructions

Binding instructions for AI-assisted work in this repository live, bundled, under [`coding_agents/`](./coding_agents/). Read these before making any change:

- [agent_principles.md](./coding_agents/agent_principles.md) — non-negotiable rules (most importantly: never assume — ask).
- [coding_guidelines.md](./coding_agents/coding_guidelines.md) — module layout, naming, theme, navigation, strings, previews.
- [coding_templates.md](./coding_agents/coding_templates.md) — copy-paste snippets for routes, screens, composables, resources, new modules.
- [build_commands.md](./coding_agents/build_commands.md) — verification, Android/web/iOS builds, resource-accessor regen.
- [security.md](./coding_agents/security.md) — secrets, PII, dependencies, web/CI guardrails.

If anything in these files conflicts with a verbal request, ask the owner before proceeding.
